# 合规与伦理清单

发布前必读。本 Skill 只做娱乐向形象建议与 AI 预览，不提供医疗、心理或身份识别服务。

## 1. AI 生成内容标识（中国）

依据《人工智能生成合成内容标识办法》（国信办通字〔2025〕2 号，2025-09-01 施行）：

- **显式标识**：AI 生成的图片需在适当位置添加可明显感知的文字/图形提示；视频起始画面和播放周边适当位置需添加显著提示。本 Skill 的做法：画面角落「AI 生成·颜值上限预览」+ 片尾/文案「本内容含 AI 生成画面」。
- **隐式标识**：生成服务提供方应在文件元数据中添加生成合成属性信息；平台会核验并补充。不要使用去水印/擦除元数据的工具处理成品。
- **用户义务**：发布者应主动声明并使用平台提供的标识功能。抖音已上线 AI 内容标识与元数据读写功能；未主动声明的疑似 AI 内容，平台会补充标识。
- **禁止行为**：恶意删除、篡改、伪造、隐匿标识；为他人提供去标识工具或服务。

参考：
- https://www.gov.cn/zhengce/zhengceku/202503/content_7014286.htm
- https://www.cac.gov.cn/2025-03/14/c_1743654685899683.htm

## 2. 肖像、隐私与授权

- 只处理本人照片，或持有出镜者明确授权的照片；对未成年人需监护人同意。
- 不上传、不留存、不再分发用户照片；生成完成后按用户要求删除临时文件。
- 不将照片用于身份识别、情绪推断、健康推断或训练数据收集。
- 不为他人生成「换脸到不当场景」的内容。

## 3. 容貌评价伦理

- 分数是娱乐向参考，受光线、角度、表情影响，不构成对真实外貌的客观评价。
- 禁止外貌羞辱、身材羞辱、年龄歧视、性别刻板印象与族裔刻板印象。
- 不制造容貌焦虑：每条诊断必须配一个「立刻可做」的低门槛动作。
- 不承诺医美效果、不推荐处方药、不替代专业医疗意见。
- 避免将特定明星面容作为改造目标；可以说「某种风格氛围」，不能说「把你改成某某」。

## 4. 平台内容规范

- 标题与封面不夸大、不虚假；分数只作节目效果说明。
- 不诱导未成年人打赏、消费或投稿个人信息。
- 评论区引导仅限互动，不收集手机号、住址、身份证等隐私信息。
- 商业推广需按平台规则标注广告/合作。

## 5. 临时图片数据与自动清理

生成的人像预览图与前后对比图属于敏感个人数据，按以下规则处理：

- **只存本地**：输出到工作区 `generated-images/`，该目录已被 `.gitignore` 忽略；**绝不将任何用户照片或生成图提交到 GitHub 或任何公开仓库**。
- **下次自动清除**：Skill 每次运行的第一步调用 `scripts/cleanup.py`，删除上一次生成的图片。这样人像不会跨会话留存，用完即弃。
- **用户可提前清除**：任何时候都可运行 `python scripts/cleanup.py` 立即删除；`--dry-run` 只看不删，`--keep 1` 保留最新一张。
- **交付即告知**：报告里必须写明「本次图片为临时文件，下次运行或手动执行清理后自动删除」。
- **示例文件例外**：`examples/` 里只放文字示例（JSON/Markdown），不放真实人像。

## 6. 一键检查清单

```
[ ] 照片为本人或已获授权
[ ] 生成图有显式 AI 标识
[ ] 文案与发布页已声明 AI 生成
[ ] 分数附带娱乐向免责声明
[ ] 没有侮辱性表述和效果承诺
[ ] 没有去除水印或元数据的行为
[ ] 没有收集或公开个人隐私信息
[ ] 生成图片只存本地 generated-images/，未提交 GitHub
[ ] 已告知用户图片为临时文件、下次运行自动清除
```
