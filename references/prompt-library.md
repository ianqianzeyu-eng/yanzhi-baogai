# AI 改造预览提示词库

使用图像生成工具时：把原图作为 `image1` 传入（图生图），`input_fidelity` 设为较高值以保身份；每次生成都要在画面角落加显式标识文字（不超过 16 字），例如「AI 生成·颜值上限预览」。

## 通用安全前缀（每个提示词都要带）

```
保持人物可识别的身份特征与五官比例，真实皮肤质感与自然光影，不磨皮成塑料感，不改变族裔、年龄与性别表达，不复制任何具体明星的面容。竖屏 9:16 人像，背景简洁。
```

## 通用负面约束

```
不要夸张美瞳、不要网红蛇精脸、不要过度磨皮、不要变形手指与眼镜、不要改变发型到无法辨认、不要添加文字水印以外的字幕、不要把生成图描述为真实照片。
```

## 模板 A：眼镜 / 中庭优化（对应「摘掉眼镜，鼻子都变小了」）

```
保留同一人物与拍摄场景，将粗框眼镜换成极细金属框或无框眼镜，眉眼完整露出；中庭视觉更清爽，鼻梁线条更利落；自然柔和的侧前方光线，表情放松；{通用安全前缀}
```

## 模板 B：发型与头脸比（少年感 / 氛围感）

```
保持人物身份特征，头发蓬松度提升，额角与鬓角做柔和修饰，露出部分眉眼与颈部线条；发型方向 {中分/三七分/八字刘海}；发色维持原色或接近原色；{通用安全前缀}
```

## 模板 C：男生清爽上镜（伪素颜）

```
保留原生皮肤质感与轻微瑕疵，只做均匀肤色与泛红弱化；眉毛顺着毛流补齐，眼神明亮自然；穿搭换成 {白衬衫/深色针织/简洁 T 恤}，领口干净；{通用安全前缀}
```

## 模板 D：女生氛围感（原生感）

```
轻薄底妆保留真实肤质，橘杏色腮红大面积轻扫并弱化边界，眼下三角区与鼻头用哑光提亮；唇色为裸粉或豆沙薄涂；发型 {锁骨发/低马尾/自然卷}；{通用安全前缀}
```

## 模板 E：穿搭与配饰替换（原片「再换上对应的穿搭和配饰」）

```
保持人物面部与身形不变，只更换穿搭为 {风格描述：都市简约/学院少年/复古港风/韩系氛围}；领口修饰肩颈线条，配饰选择 {细框眼镜/耳线/棒球帽/围巾}；服装合身、色彩为 {中高明度/低饱和}，背景保持原场景；{通用安全前缀}
```

## 模板 F：光线与机位翻盘（低成本改造演示）

```
同一人物、同一表情与服装，机位略高于视线并后退半步减少畸变；45 度侧前方柔光，背景简化或轻微虚化；脸部受光均匀、下颌线自然收紧；{通用安全前缀}
```

## 模板 G：多人拼贴封面（视频封面，非人像生成）

```
杂志撕纸拼贴风竖屏封面，左右前后对比构图，黄色粗体中文大字「爆改系列 第X期」，浅灰与米色纸张层次，真实照片质感，不出现其他可识别人物面孔；画面角落小字「AI 生成·封面设计」
```

## 参数建议

- 竖屏视频封面/预览：`1024x1536`；横版对比图：`1536x1024`。
- `quality`: medium 起，封面可 high。
- `footnote`: 如需工具侧水印，可用「AI生成预览」（≤16 字）；仍需在画面内另加显式标识，不能只依赖工具水印。
- 生成后检查：身份是否可辨、手部与眼镜是否变形、是否出现意外文字、标识是否清晰可见。

## 与其他技能联动

- `buddy-image-processing`：原图有杂物/文字水印、需要抠图或人像增强时先处理，再送入图生图。
- `humanizer` / `human-writing`：生成脚本后做口语化改写，不改数据标识。
