# 在豆包 App 中使用 / Use in Doubao

豆包 App 没有 `SKILL.md` 技能机制，它用「**智能体 = 人设提示词 + 知识库**」的方式。本目录提供了对应文件，复制粘贴即可搭出同款「颜值上限爆改师」。

Doubao App has no `SKILL.md` mechanism. It builds a bot from a **persona prompt + knowledge base**. Files below let you recreate the same "Beauty Ceiling Makeover" bot by copy-paste.

---

## 三步搭建 / 3 Steps

### 1. 创建智能体
打开豆包 App → 首页右上角 **+** → **创建 AI 智能体**（或在「我的 → 智能体」里创建）。
- 名称：`颜值上限爆改师`
- 简介：`从照片发现你的优势，给出可执行的爆改方案与短视频脚本`

### 2. 粘贴人设提示词
打开 [`persona-prompt.md`](persona-prompt.md)，复制 `==== 开始 ====` 与 `==== 结束 ====` 之间的**全部内容**，粘贴到「**设定描述 / 人设与回复逻辑**」框。
- 这是自包含版本：评分公式、六因子、话术、合规都写在里面了，**不依赖任何脚本**。
- 点「一键完善」让豆包润色也可以，但请勿删除「硬性规则」章节。

### 3.（可选）上传知识库让回答更专业
进入智能体的「**知识库**」标签 → 上传文件，选择本目录的 [`knowledge-base.txt`](knowledge-base.txt)。
- 里面有六因子公开标准、研究依据、完整口播句库、分镜模板。
- 上传后建议在配置里把相似度阈值设为 0.65-0.7、Top-K 设为 3-5。
- 不上传也能用，人设提示词已包含核心方法。

最后点右上角「**发布**」，在对话里发照片 + 说「帮我看看颜值上限」即可触发。

## 能力对照 / Capability Notes

| 能力 | WorkBuddy / 扣子 | 豆包 App |
| --- | --- | --- |
| 六因子诊断、双分数、改造清单、短视频脚本 | ✅ 原生 | ✅ 提示词内置 |
| 图生图预览 | ✅ 调用图像工具 + AI 标识 | ✅ 用豆包生图，提示词见第 4 步 |
| `score.py` / `make_comparison.py` 脚本 | ✅ 可运行 | ❌ 豆包不能跑脚本，公式已内置，对比图需自行用图片工具拼接 |
| 每次运行自动清理临时图片 | ✅ `cleanup.py` | 不适用（豆包不落盘个人照片） |

> 隐私说明：豆包版本不会在本地保存或提交你的照片；生成内容请仍按平台要求打开 AI 生成声明。
