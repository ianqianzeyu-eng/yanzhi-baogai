# 六因子评估标准
------------------------------
# 颜值评估六因子：公开标准、研究依据与局限

用途：给照片打分前读取。所有结论都要写成「照片中可见的视觉线索」，不要写成对本人真实长相的定性。

## 1. 骨相比例（权重 35%）

- **三庭**：发际线→眉骨、眉骨→鼻翼下缘、鼻翼下缘→下巴尖，古典标准各占 1/3。实际人脸普遍偏离该标准；Farkas 等人类测量研究显示多数真实面孔与古典比例有明显差异，因此只能作描述性基准。
- **五眼**：以一只眼宽为单位，面宽约等于五只眼；用于描述眼距与鼻宽关系。
- **四高三低（侧面）**：额、鼻尖、唇珠、下巴尖为高；鼻额交界、人中沟、下唇下凹陷为低。
- **和谐度**：研究反复观察到「单个器官完美 ≠ 整体好看」，鼻子/眼睛/下颌之间的相对关系比孤立数值更重要。
- **对称性**：左右差异小与吸引力评级正相关，但效应中等；照片歪头、偏侧光、单侧微笑会制造假性不对称，必须提示重新正拍确认。
- **平均脸效应**：Langlois & Roggman（1990）合成面孔研究发现接近人群平均的面孔常被评为更有吸引力；但「极端平均」不是上限，独特性与表情同样重要。
- **黄金比例**：流传最广、证据最弱。不要作为主要评分依据，只可作趣味参考。

## 2. 五官与表情（20%）

观察眉眼形态、眼裂开合、鼻翼宽度、唇形与唇色、笑容参与度。动态表情与眼神状态对整体印象影响很大；同一张脸，放松自然的表情通常比僵硬摆拍更上镜。

## 3. 皮肤与状态（10%）

观察肤色均匀度、泛红、痘印、油光、疲态。只给防晒、清洁、保湿、睡眠与光线建议；不判断疾病，不推荐处方药或具体医美项目。

## 4. 头面修饰（15%，可改造）

发型长度、蓬松度、刘海方向、发色；眼镜框型与是否遮眉眼；胡须修整；耳饰/帽子/发带。经验规律：

- 眼镜会改变鼻梁与中庭的视觉宽度，摘镜或换细框/无框常带来明显变化（与博主原片观察一致）。
- 头顶蓬松度影响头脸比；中分/侧分改变额角与下颌视觉宽度。
- 眉眼清晰度比眉毛绝对形状更重要。

## 5. 穿搭与色彩（10%，可改造）

- 领口决定肩颈线条；V 领/大领口通常更显颈部修长。
- 色彩诊断常用三个维度：冷暖（肤色与瞳发色基调）、明度（深浅）、纯度（鲜艳度）。普通人的安全区是中高明度、中低纯度，用局部亮色点缀。
- 风格量感：五官量感大适合更明确的廓形与配饰；量感小适合轻薄、简洁、留白多的搭配。

## 6. 镜头与光影（10%，最易翻盘）

- 机位高度：略高于视线常显脸小、拉长颈部；过低容易显下颌与鼻孔。
- 距离与焦段：手机离太近会畸变；后退半步并裁切更好。
- 光位：45° 侧前方柔光最能建立立体感；顶光与正午硬光最容易暴露疲态。
- 背景：杂乱背景降低主体辨识度；纯色或虚化背景提升整体质感。
- 表情与姿势：微收下巴、舌顶上颚、肩膀下沉，比夸张修容更有效。

## 7. 评分纪律

1. 每个维度必须有「照片证据 + 可执行动作」两栏，不能只写分数。
2. 「颜值上限分」只允许提升可改造项（头面修饰、穿搭色彩、镜头光影），骨相与五官维持现值；因此上限差距一般在 1.0-2.5 分之间。差距过大说明评分不严谨。
3. 任何分数都要附：「娱乐向参考，受拍摄角度与光线影响，不构成客观评价」。
4. 禁止使用带有侮辱性的描述；把「缺点」改写成「可优化点」。

## 参考来源

- 百度百科「高颜值」：三庭五眼、四高三低与常见几何标准整理。
- Farkas et al., *Plastic and Reconstructive Surgery* 75:328-338 (1985)；Le et al., *Aesthetic Plastic Surgery* 26:64-69 (2002)：不同人群的古典比例测量。
- Langlois & Roggman, *Psychological Science* 1:115-121 (1990)：平均脸效应。
- Kiekens et al., *AJODO* 133:188.e1-8 (2008)：理想比例/角度与实际评级的弱相关。
- Face Analysis Lab / Your Body Report 科普综述：对称性、平均性、三庭五眼与黄金比例的证据强度对比（均为公开网页，访问于 2026-11-22）。

## 3. 单条视频的内容结构

从可见字幕帧还原（以第 8 集、第 10 集为例）：

1. **0-3 秒钩子**：标题式大字「我能看到你的颜值上限 8.0 / 10.0」，先给分数制造悬念。
2. **诊断叠加**：在原图上压短句字幕，例如：
   - 「摘掉眼镜，鼻子都变小了是吧」

3. **改造动作**：依次展示眼镜/发型/妆容/穿搭/配饰变化，常以多人连剪提高信息密度。
4. **反差揭示**：改造后正面/侧脸定格，配「这哥们找到我时」式的叙事字幕。
5. **CTA**：「关注➕评论 随机抽取粉丝爆改」；第 10 集改为致谢与价值观收尾。

## 4. 可复用文案公式

- 标题：`第X集 | 我能看到你的颜值上限 {分数}.0 {CTA} #{话题}`
- 诊断句：`{具体动作} + {反直觉结果}`，例如「摘掉眼镜，鼻子都变小了」。
- 调侃句：`{轻微吐槽} + {夸张赞美}`，例如「小心眼易怒，改出来个男模」。注意分寸，不对真实用户使用冒犯性词汇。
- 价值观句：`你很好看，只是还没被发掘` / `挖掘与众不同的闪光点，找到每个人的风格`。
- CTA：`关注 + 评论，随机抽取粉丝爆改` / `关注加点赞，优先抽取改造`。

# 图生图提示词模板
------------------------------
# AI 改造预览提示词库

使用图像生成工具时：把原图作为 `image1` 传入（图生图），`input_fidelity` 设为较高值以保身份；每次生成都要在画面角落加显式标识文字（不超过 16 字），例如「AI 生成·颜值上限预览」。

## 通用安全前缀（每个提示词都要带）

```
保持人物可识别的身份特征与五官比例，真实皮肤质感与自然光影，不磨皮成塑料感，不改变族裔、年龄与性别表达，不复制任何具体明星的面容。竖屏 9:16 人像，背景简洁。
```

## 通用负面约束

```
不要夸张美瞳、不要网红蛇精脸、不要过度磨皮、不要变形手指与眼镜、不要改变发型到无法辨认、不要添加文字水印以外的字幕、不要把生成图描述为真实照片。
```

## 模板 A：眼镜 / 中庭优化（对应「摘掉眼镜，鼻子都变小了」）

```
保留同一人物与拍摄场景，将粗框眼镜换成极细金属框或无框眼镜，眉眼完整露出；中庭视觉更清爽，鼻梁线条更利落；自然柔和的侧前方光线，表情放松；{通用安全前缀}
```

## 模板 B：发型与头脸比（少年感 / 氛围感）

```
保持人物身份特征，头发蓬松度提升，额角与鬓角做柔和修饰，露出部分眉眼与颈部线条；发型方向 {中分/三七分/八字刘海}；发色维持原色或接近原色；{通用安全前缀}
```

## 模板 C：男生清爽上镜（伪素颜）

```
保留原生皮肤质感与轻微瑕疵，只做均匀肤色与泛红弱化；眉毛顺着毛流补齐，眼神明亮自然；穿搭换成 {白衬衫/深色针织/简洁 T 恤}，领口干净；{通用安全前缀}

## 模板 F：光线与机位翻盘（低成本改造演示）

```
同一人物、同一表情与服装，机位略高于视线并后退半步减少畸变；45 度侧前方柔光，背景简化或轻微虚化；脸部受光均匀、下颌线自然收紧；{通用安全前缀}

```
杂志撕纸拼贴风竖屏封面，左右前后对比构图，黄色粗体中文大字「爆改系列 第X期」，浅灰与米色纸张层次，真实照片质感，不出现其他可识别人物面孔；画面角落小字「AI 生成·封面设计」
```

## 参数建议

- 竖屏视频封面/预览：`1024x1536`；横版对比图：`1536x1024`。
- `quality`: medium 起，封面可 high。
- `footnote`: 如需工具侧水印，可用「AI生成预览」（≤16 字）；仍需在画面内另加显式标识，不能只依赖工具水印。
- 生成后检查：身份是否可辨、手部与眼镜是否变形、是否出现意外文字、标识是否清晰可见。

## 与其他技能联动

- `buddy-image-processing`：原图有杂物/文字水印、需要抠图或人像增强时先处理，再送入图生图。
- `humanizer` / `human-writing`：生成脚本后做口语化改写，不改数据标识。

# 合规与伦理清单

发布前必读。本 Skill 只做娱乐向形象建议与 AI 预览，不提供医疗、心理或身份识别服务。

## 1. AI 生成内容标识（中国）

依据《人工智能生成合成内容标识办法》（国信办通字〔2025〕2 号，2025-09-01 施行）：

- **显式标识**：AI 生成的图片需在适当位置添加可明显感知的文字/图形提示；视频起始画面和播放周边适当位置需添加显著提示。本 Skill 的做法：画面角落「AI 生成·颜值上限预览」+ 片尾/文案「本内容含 AI 生成画面」。
- **隐式标识**：生成服务提供方应在文件元数据中添加生成合成属性信息；平台会核验并补充。不要使用去水印/擦除元数据的工具处理成品。
- **用户义务**：发布者应主动声明并使用平台提供的标识功能。抖音已上线 AI 内容标识与元数据读写功能；未主动声明的疑似 AI 内容，平台会补充标识。
- **禁止行为**：恶意删除、篡改、伪造、隐匿标识；为他人提供去标识工具或服务。

参考：
- https://www.gov.cn/zhengce/zhengceku/202503/content_7014286.htm
- https://www.cac.gov.cn/2025-03/14/c_1743654685899683.htm

## 2. 肖像、隐私与授权

- 只处理本人照片，或持有出镜者明确授权的照片；对未成年人需监护人同意。
- 不上传、不留存、不再分发用户照片；生成完成后按用户要求删除临时文件。
- 不将照片用于身份识别、情绪推断、健康推断或训练数据收集。
- 不为他人生成「换脸到不当场景」的内容。

## 3. 容貌评价伦理

- 分数是娱乐向参考，受光线、角度、表情影响，不构成对真实外貌的客观评价。
- 禁止外貌羞辱、身材羞辱、年龄歧视、性别刻板印象与族裔刻板印象。
- 不制造容貌焦虑：每条诊断必须配一个「立刻可做」的低门槛动作。
- 不承诺医美效果、不推荐处方药、不替代专业医疗意见。
- 避免将特定明星面容作为改造目标；可以说「某种风格氛围」，不能说「把你改成某某」。

## 4. 平台内容规范

- 标题与封面不夸大、不虚假；分数只作节目效果说明。
- 不诱导未成年人打赏、消费或投稿个人信息。
- 评论区引导仅限互动，不收集手机号、住址、身份证等隐私信息。
- 商业推广需按平台规则标注广告/合作。

## 5. 临时图片数据与自动清理

生成的人像预览图与前后对比图属于敏感个人数据，按以下规则处理：

- **只存本地**：输出到工作区 `generated-images/`，该目录已被 `.gitignore` 忽略；**绝不将任何用户照片或生成图提交到 GitHub 或任何公开仓库**。
- **下次自动清除**：Skill 每次运行的第一步调用 `scripts/cleanup.py`，删除上一次生成的图片。这样人像不会跨会话留存，用完即弃。
- **用户可提前清除**：任何时候都可运行 `python scripts/cleanup.py` 立即删除；`--dry-run` 只看不删，`--keep 1` 保留最新一张。
- **交付即告知**：报告里必须写明「本次图片为临时文件，下次运行或手动执行清理后自动删除」。
- **示例文件例外**：`examples/` 里只放文字示例（JSON/Markdown），不放真实人像。
